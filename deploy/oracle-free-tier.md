# Oracle Cloud 永久免费服务器 - 注册与交付指南

> 目标：拿到一台**永久免费**的云服务器（4核24G ARM），7×24 跑自动投递。
> 注册成功 = 你只需要把实例 IP 发我，剩下我全部远程装好。

---

## 1. 注册前准备清单

| 事项 | 要求 |
|------|------|
| 银行卡 | **Visa / 万事达 实体借记卡或信用卡**（开通"境外无卡支付"）；❌ 银联单标、❌ 一次性虚拟预付卡（官方明确拒绝）；虚拟卡通过率低 |
| 卡内余额 | 留 1-2 美元等值（验证做 ~$1 预授权，3-7 天自动解冻，**不实扣**） |
| 账单地址 | 用银行记录的**英文地址**（去银行 APP 复制，别自己翻译） |
| 邮箱 | Gmail / Outlook（国内邮箱也有人过，Outlook 更稳） |
| 手机号 | 国内手机号可用（能收国际短信） |
| 网络 | **家里宽带或手机 5G 直连，全程不要开代理/VPN**（机房 IP/代理是最大拒因） |

## 2. 注册要点（一次填对最省事）

1. 打开 https://www.oracle.com/cn/cloud/free/ → 点「立即免费试用」
2. 姓名用**拼音**，与银行卡完全一致；地址与银行卡账单一致
3. 邮箱验证 → 设置密码（12位+大小写+数字+符号，**不要包含姓名拼音**）
4. **主区域选择**（选定后不可改，Amazon 免费机器只能建在此区）：
   - 亚太热门区（东京/首尔/新加坡）：离你近，但免费 ARM **常年"容量不足"抢不到**
   - ✅ 推荐：**凤凰城 (us-phoenix-1)** 或 伦敦 / 法兰克福——免费 ARM 最容易开出来
   - 地区不影响投递效果（搜索目标还是香港岗位），只影响你 SSH 管理延迟
5. 添加付款验证方式 → 看到 `Oracle 预授权` 短信是正常的
6. 点「开始我的免费试用」等待结果（页面转圈 = 风控跑分）
7. ✅ 成功：进入控制台；❌ 失败（ABC/无法完成注册）：**换新邮箱 + 换手机热点 + 隔天再试**，别用同卡同邮箱反复试（被拒两次以上易进黑名单）

> ⚠️ 黄金守则：注册成功后 **24 小时内先别创建实例**，登录看看即可。

## 3. 创建实例（关键：粘贴我的公钥）

1. 控制台 → 计算 → 实例 → 创建实例
2. 映像：**Ubuntu 22.04 或 24.04**
3. 形状：**Ampere / VM.Standard.A1.Flex**，选 **4 OCPU / 24 GB**（Always Free 额度内）
   - 若提示 "Out of host capacity"：换可用域(AD)重试，或稍后再试（热门区常态）
4. **添加 SSH 密钥** → 选「粘贴公钥」→ 粘贴下面这把（部署用的，不是你的账号密码）：

```
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIADT3uJx0EAVUqVb0LzVe2F+x4BT+s4p6xZ1HHPKQB3O linkedin-auto-deploy
```

   > 已存在的实例也可以：SSH 进去后执行
   > `mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIADT3uJx0EAVUqVb0LzVe2F+x4BT+s4p6xZ1HHPKQB3O linkedin-auto-deploy" >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys`

5. 创建完成后，记录**公网 IP**，发我即可。

## 4. 网络/防火墙说明（不用改）

- Oracle 默认**只开 22 端口**（SSH）——刚好够用：自动化只跑"出站 HTTPS"，VNC 登录走 SSH 隧道，无需额外开放端口
- 不用动 iptables / 安全列表
- ⚠️ 不要给实例配"公共 IP 之外"的复杂网络；保持默认即可

## 5. 交付给我什么

```
1) 公网 IP
2) SSH 登录用户名（Oracle Ubuntu 默认是 ubuntu；其他厂商可能是 root）
3) 确认公钥已粘贴（第 3 步）
```

我拿到后执行 `deploy\deploy-from-windows.ps1`（已备好），自动完成：
安装依赖 → 部署代码 → 迁移简历+投递历史 → 装好定时器 → 验证。
然后你只需配合做一次 **VNC 登录**（3 分钟，见 deploy/README.md 第 4 节）。

## 6. 常见问题

| 问题 | 处理 |
|------|------|
| ARM 一直"容量不足" | 换可用域重试；或直接用 **自动抢购脚本** `deploy/oracle-grab-arm.py`（官方 API 轮询，放量瞬间自动抢到，已通过桩测试） |
| 抢购脚本用法 | `pip install oci oci-cli` → `oci setup config` → `python deploy/oracle-grab-arm.py --region us-phoenix-1` |
| 注册被拒 (ABC) | 换邮箱+换网络+隔天再试；检查卡是否开通境外支付 |
| 想先用起来 | 也可以先建 **AMD micro (1G)** 实例，但跑 Chrome 很吃力，仅建议过渡 |
| 账号被回收 | Always Free 闲置 30 天会被回收；我们每天运行，不会闲置 |
